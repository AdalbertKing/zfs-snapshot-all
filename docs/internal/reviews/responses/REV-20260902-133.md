### Remaining risk

The sentinel proves that THIS comment's command is not run; the empty-stderr
half is what generalises to any future span, because an unquoted heredoc that
expands prose either runs something (usually loudly, `command not found`) or
fails to parse it. A span that happens to name an existing command with no
output would still slip past the stderr half and be caught only by the static
grep above it -- the two checks are kept together for that reason.
