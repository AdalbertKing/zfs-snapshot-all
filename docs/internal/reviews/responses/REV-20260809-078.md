# Response to REV-20260809-078

## F1 — ACCEPTED (IMPLEMENTED)

### Analysis

The finding is correct and I am not disputing any part of it. The leading block
said `Data odświeżenia: 2026-08-07` and ended with the flat claim that nothing
from long recursion options, profiles or restore is implemented. At the reviewed
implementation, two thirds of that sentence were false: Stage 2.3 ships
`--recursive=atomic|flat|no` in both engines, and `lib-profile.sh` is production
code.

The mechanism worked exactly as documented and that is the uncomfortable part.
`status-covers-digest` proves the file was refreshed in the same prospective
commit as the files that declare the obligation. It cannot prove the prose says
anything true, and commit `76bcc4d` already said so. What happened here is the
failure that limitation predicts: later edits refreshed the digest and the lower
sections, and the block whose entire purpose is to be current was left alone.

I want to name why it survived so long, because it is not carelessness alone.
The leading block had grown into a narrative — Stage 0 on pve0, the lock-file
repair, the recursion migration, the monitor change — each addition true when
written. A block that accretes is one nobody rewrites, because every sentence in
it still describes something that really happened. The defect is structural: the
block was doing two jobs, *current state* and *changelog*, and the second job
protects the first from being edited.

### Implemented change

1. **New leading current-state block**, dated 2026-08-09, built as a table with
   one row per capability and exactly two values, shipped or not shipped, with a
   pointer to where the detail lives. It answers the reviewer's required list
   item by item: 2.1, 2.2, 2.3, freeze, reconcile, profile boundary, profile
   runtime, single-host orchestration, restore.

   Deleting it would have removed the evidence that the claim was ever made.

   drzewa" heading.** Requirement 4 says do not rewrite old entries to look
   current; requirement 3 says fix the stale sentence. The only reading that

   did.

5. **No second copy of volatile detail** (requirement 5). The new block points at
   `REVIEW_LEDGER.md`, `OPEN-THREADS.md`, `DELIVERIES.md`, `ENGINE-FREEZE.md` and

digest proves synchronisation, not truth. A future edit can refresh the marker
