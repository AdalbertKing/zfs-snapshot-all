## F2 — the runbook reproduced a stale "unimplemented" message — IMPLEMENTED

The more serious of the two, and worth stating plainly: `pause-client` still
told its operator that hard disable was *"a separate, unimplemented stage"* —
true when written, false since REV-052 closed the package — and I pasted that
line verbatim into the new runbook, one section above the instructions for
using the very feature it denies. A stale CLI string became documentation.

The notice now names the stronger control instead of denying it exists:

```text
LIMITATION: this is logical pause -- a manual snapget.sh/snapsend.sh that
OMITS '-L pve2' is not blocked. For enforcement at the peer, including
unlabeled manual commands, use: zfs-backup.sh disable-client pve2
```

A limitation is only useful to the person reading it if it also says what
does *not* have that limitation. Pinned by a new case asserting both halves —
the pointer to `disable-client` is present, and the word `unimplemented` is
gone — so it cannot rot back the same way. The runbook example was
regenerated by running the real command, not retyped.
