## F1 — P1 BLOCKING — `tx_guard` ignores failure to create the rollback copy

### Evidence

`test/reviewctl.sh` `tx_guard()` adds each live path to `TX_FILES`, then runs
`mkdir`, `cp -p`, or the absent-file-list append without checking any result:

```bash
TX_FILES+=("$f")
mkdir -p "$TXDIR/present/..."
cp -p "$f" "$TXDIR/present/..."
```

The writer then mutates the live role artifact. If the later generator or
verifier refuses, `tx_die()` calls `tx_restore()`. But a failed snapshot created
no file under `present/`, and the live path was not recorded under `absent/`, so
`tx_restore()` has no matching branch and silently leaves the mutation in place.
It then deletes the transaction directory and exits nonzero.

This violates the core consensus property that failure leaves the role artifact,
generated files, working tree, and index unchanged. A nonzero exit is not enough:
the next run reads the already-mutated reviewer fact.

### Acceptance criteria

1. Snapshot setup is a hard precondition. Failure of any snapshot directory,
   file copy, metadata-preserving copy, or absent-file record must stop before a
   live artifact is changed.
2. Restoration checks every operation. If restoration itself cannot complete,
   report the exact unrecovered path and retain the usable transaction backup
   for manual recovery; do not silently delete the only copy.
3. Add the discriminating control above: force one snapshot copy to fail, then
   force a later canonical-fact validation failure. The writer must return
   nonzero and the role artifact, ledger, routing view, working tree, and index
   must all remain byte-identical. It must fail against current canonical
   `e33b6670739c9b1f439bbfe1f3038ff392424509` for the shown reason.
4. Add the symmetric restoration-failure control and prove the backup survives
   with an actionable path in the diagnostic.
5. Preserve the already-correct separate approve/close publications, exact
   current-implementation check, published-parent checks, delivery acknowledgement,
   and idempotent replay verification.
