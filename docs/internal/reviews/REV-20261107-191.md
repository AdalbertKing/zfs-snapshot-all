## F1 — `-I` sends the intermediate snapshots that `-E` filtered out

- Severity: **P1**.
- Blocking: **yes for release of the PR #1111 first-copy history claim**.
- Affected: `snapget.sh` `process_dataset` first-copy mirror path and ordinary
  incremental mirror path; `test/scenarios/run.sh` S8.

### Contract and evidence

The public `-E` option promises to omit snapshot families by prefix. In
`snapget.sh`, `process_dataset` filters `src_snaps` for `-E` at lines 1619–1631,
then optionally filters by `-m` at 1643–1651. PR #1111 chooses the oldest
remaining snapshot for the first full mirror send, then builds
`zfs send ... -I oldest newest` at 2104–2115. The ordinary common-base path
also selects `-I` by default at 2049–2064. OpenZFS specifies that `zfs send
-I` sends **all** intermediary snapshots between the two endpoints; the
filtered array has no effect on that stream. This is an inference from the
exact command and the [OpenZFS `zfs-send(8)` definition](https://openzfs.github.io/openzfs-docs/man/master/8/zfs-send.8.html),
not a claim of a live ZFS run.

S8 constructs precisely this case: `automated_daily_1`,
`automated_daily_2`, `__replicate_100-0_1__`, `automated_daily_3`,
`__replicate_100-0_2__`, then invokes `snapget -e -M -E __replicate_`.
Its inventory assertion removes `__replicate_` from the *observed target*
with `grep -v` before comparing, so it passes even if the excluded snapshot
was copied. The source contains an excluded snapshot between the first and
last eligible endpoints. The later `__replicate_100-0_2__` is outside the
interval and is not proof either way.

### Failure mode and required outcome

The first copy promises to carry eligible history without copying Proxmox's
reserved `__replicate_` snapshots. The new `-I` stream includes the reserved
snapshot inside the interval, contrary to the `-E` contract. The same
endpoint-only filtering can recur after a common snapshot on later runs.
Copy only eligible snapshots while preserving the intended data and history
semantics, or explicitly obtain an Owner decision to change the public `-E`
contract before publication. Do not treat a filtered assertion as evidence of
an unfiltered target inventory.
