## F1 — P1: Ins starts a template dialog from a stale selected profile

- Severity: **P1**
- Blocking: **yes for treating post-dialog template actions as freshly
  targeted**
- Affected: `tui/zfs-tui.py`, `UI.ACTION_KEYS`, `UI.key()` and
  `UI.template_action()`.

### Evidence

When a full background collection fails, `poll_bg()` deliberately keeps the
old rows and sets `bg_failed = True`. `UI.key()` then blocks only:

```python
ACTION_KEYS = ("F7", "F8", "F9", "enter", "del", "e")
```

`ins` is absent. On the Templates screen it is row-dependent: it reads the
selected profile from the retained list and dispatches
`save-profile --ask --from=<selected>`.

The safe reproducer imports the shipped TUI, substitutes only the read-only
collector and the final dialog sink, and compares `Del` with `Ins` after the
same failed refresh:

```bash
python3 docs/internal/reviews/evidence/REV-20261023-173-stale-template-ins.py \
  tui/zfs-tui.py
```

Result on the inspected main (exit 0 means the bug was reproduced exactly):

```text
bg_failed=True stale_profile=stale-template
negative_control_del result=stay scheduled=[] blocked=True
stale_ins result=shell scheduled=[['/tmp/zfs-backup.sh', 'save-profile', '--ask', '--from=stale-template']]
```

The existing REV-172 regression is green because it asserts failed-refresh
blocking only for `Del`; it does not exercise `Ins` on Templates.

### Failure mode and impact

After a template dialog returns, a failed full refresh leaves the old profile
list visibly stale. `Del` correctly fails closed, but `Ins` immediately opens
creation based on the stale selected identity. The operator can therefore
copy a profile that was removed or changed by the preceding dialog or by
concurrent administration, despite the GUI's failed-refresh safety message.
The downstream command may reject a missing profile, but a still-existing and
changed profile is a valid yet unintended base.

This evidence proves stale command selection only. It executes no command and
does not claim that a live profile was modified.
