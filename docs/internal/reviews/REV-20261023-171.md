### Evidence

The formatter builds the target map, then iterates only over `source`:

```python

out, same = [], True
for t in d.get("source") or []:
```

It never checks for a retention-bearing target tier absent from the source.

runs no daily retention while the target still retains/prunes the daily tier.

### Impact

After intentionally or accidentally disabling a source tier, the principal
GUI summary can tell the administrator that the source retains the same
recovery windows as the copy. During loss of the target copy, the supposedly
matching daily (or other missing) source recovery point is not available. The
review demonstrates false safety readback, not deletion or an observed outage.
